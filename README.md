# AutoFix

Uma aplicação web desenvolvida com HTML, CSS e JavaScript, criada para apresentar serviços de manutenção automotiva, revisão geral, troca de óleo, freios, suspensão e diagnóstico automotivo, com foco em qualidade, segurança e confiança.

## Demonstração

[ Clique aqui para acessar o AutoFix ]()

## Funcionalidades

- Apresentação da oficina
- Apresentação dos serviços automotivos
- Revisão geral
- Troca de óleo
- Manutenção de freios e suspensão
- Diagnóstico automotivo
- Galeria de imagens dos serviços
- Formulário para solicitação de orçamento
- Integração com WhatsApp
- Envio dos dados do orçamento pelo WhatsApp
- Máscara de telefone no formulário
- Menu responsivo para dispositivos móveis
- Botão flutuante do WhatsApp
- Layout responsivo
- Navegação entre seções da página
- Ano automático no rodapé

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts (Montserrat)
- WhatsApp

## Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de HTML, CSS e JavaScript, trabalhando principalmente com criação de interfaces web, estilização de páginas, responsividade, navegação entre seções, manipulação do DOM, validação de formulários e integração com o WhatsApp para facilitar a solicitação de orçamentos e o contato com os clientes.
